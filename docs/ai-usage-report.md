# AI Usage Report

## Tools Used and Use Cases

I used ChatGPT as an AI-assisted development tool during this assignment. I used it to brainstorm a simple portfolio structure, suggest responsive layout ideas, generate an initial HTML/CSS/JavaScript foundation, explain JavaScript interactions, and review the documentation structure.

## Benefits and Challenges

AI helped me start the project faster and gave me ideas for organizing files and creating a responsive layout. It also helped explain concepts such as CSS Grid, media queries, DOM events, and localStorage. A challenge was that AI-generated code may contain design choices or code that does not exactly match my requirements, so I had to review and test every part.

## Learning Outcomes

I learned how to connect an HTML file to separate CSS and JavaScript files, create sections using semantic HTML, use CSS Grid and Flexbox, add a mobile media query, handle a form with JavaScript, and save a theme preference using localStorage. I also learned that AI is more useful when I ask focused questions and verify the result myself.

## Responsible Use and Modifications

I did not submit AI output without review. I changed the content, project names, colors, layout, text, comments, and JavaScript behavior. I tested the page by opening it in a browser, resizing the window, checking navigation links, switching the theme, and submitting the form. I used AI as a learning and development assistant while keeping responsibility for understanding and adapting the final work.
