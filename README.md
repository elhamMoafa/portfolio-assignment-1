# Assignment 1 

## Personal Portfolio Website

This project is a simple responsive personal portfolio created with HTML, CSS, and JavaScript. It includes an About Me section, two projects, a Skills section, a Contact form, and interactive features.

## Features

- Responsive layout for desktop, tablet, and mobile.
- Semantic HTML structure.
- CSS Grid and Flexbox layouts.
- Mobile navigation menu.
- Light/dark theme toggle saved with localStorage.
- Greeting message based on the time of day.
- Client-side contact form validation.

## Run Locally

1. Download or clone the repository.
2. Open `index.html` in a modern web browser.
3. For the best development experience, use the Live Server extension in Visual Studio Code.

No database, backend, or package installation is required.
